# 24 题三轮配对开发协议（执行前固定）

本协议属于 DEVELOPMENT_ONLY / UNREVIEWED，人工审核数 0。PV1601–PV1624 是新任务标识及新目标文本，正常、异常参数、权限、资源/状态各六题，课程与工单各覆盖。它们是已有五类受支持模板的实例，不是 24 种独立语义；三轮是 72 次运行，不能称为 72 道独立题。源代码定义位于 paired_tasks.py，旧 FC/FE/GD/GW 任务与成绩不改。

异常参数题仅测已批准策略下的本地参数拒绝，不增加负向 HTTP 策略或声称验证服务端异常处理。18 个位置应零业务请求。其余 30 个健康位置、24 个注入缺陷位置；缺陷包括跨角色读取、回读名称/ID/工单主题和关闭未生效。21 个缺陷位置可按现有只读协议支持症状结论，3 个关闭未生效位置因原失败为 PATCH、只允许 GET 复核，结论必须证据不足；不扩展模型的根因判断权限。

对照为开发者编写的固定 pytest：独立用 HTTPX/ASGI 调用相同临时服务及显式断言，不使用 Planner 或 AgentTest Executor。它并非真实独立人工编写的计时实验；没有人工作时数据。参数题使用相同已批准长度/类型/枚举边界作本地拒绝。每个缺陷额外执行相同目标的健康配对；Agent 对已批准生成计划也作同计划健康复核（Fake 输入重放，不追加模型）。故障造成的 pytest 失败必须保留，预计 24 failed / 48 passed，退出 1 是对照所发现故障，不隐藏为通过。

执行前保存源码/提交/工作区、任务全文、契约/目标/策略摘要、规划上下文/请求哈希、批准调查能力、提示及 Schema 哈希、模型配置与顺序。按轮次再按编号串行。固定最多 288 次模型、6,939,648 Token 预留；每 run 初始规划加至多三次反馈模型、两次只读调查，模型 60 秒、工作流 300 秒，无隐式重试。使用现有 ecnu-plus / ChatECNU 账户。未知用量、传输/基础设施故障停止后续付费位置；已知用量的执行前拒绝继续既定排期。不因失败重排或补跑。

分别报告 DSL、策略、意图、task_satisfied；参数安全拒绝和预期分支拒绝另列（预期分支仅接受已固定的 OPENAPI_VALUE_LENGTH / TYPE / ENUM，不把任意意图拒绝算参数定位正确），不把拒绝算业务完成。检出缺陷须匹配预先指定失败断言，并且同计划健康目标通过。健康目标的断言失败算误报；计划拒绝算未完成，不能伪称无缺陷。调查的相关选择指已批准 GET、资源所有者和对应读取接口；有效证据须通过原 supported_finding 的同资源/角色/失败字段判据。调用成功并不等于证据有效。结论按预设症状与确定性支持分别评分，证据不足按独立三位置计数。

保留每个位置、报告摘要、计划哈希证据、耗时、用量和固定 pytest 的 JSON/JUnit/日志。所有业务请求均为本地内存 ASGI；真实模型请求、模拟调用、第三方业务 HTTP、数据库写入分别列出。封印后冷重评分不启动目标或模型，缺失位置留在 72 分母中。公开摘要不含任务正文、响应正文或凭据。

运行：`python scripts/check_paired_development.py --output runs/<new>` 使用 Mock 模型；在干净提交上增加 `--model-env .env` 执行预定真实开发排期。`--verify runs/<archive>` 只冷核对。真实独立留出集必须另由独立人工提供和审核；本轮使用过的 24 题不得转为独立留出题。正式评测仍未完成，门禁不放宽。
