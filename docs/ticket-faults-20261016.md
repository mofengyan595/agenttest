# 工单同计划配对故障验证（2026-10-16）

本轮只补齐第二个自有业务域的真实模型故障证据，复用现有 Workflow、Executor、
Verifier、通用提示及策略；不改被测业务、断言、授权或既有任务。

三条新开发任务见 [G701–G703](../examples/ticket-fault-development.json)：
新建后读取核对主题、本人读取后验证 visitor 被拒绝、关闭后核对状态。
任务使用新的合成主题与固定优先级；不是三个全新业务类型或独立留出样本。
公开策略用途沿用上一轮完整六条目录，不按答案裁剪。

每题只生成一次，先在全新正常目标执行；完整通过 DSL／Policy／Intent／执行断言
后，才将**同一个计划**分别用于另一个全新正常目标和指定故障目标。
配对重放为事先规定的固定执行，不是失败后补跑或再调用模型。
三种故障仅由运行器在目标工厂选择，不进入模型请求：

| 任务 | 故障 | 必须实际失败的断言 |
| --- | --- | --- |
| G701 | 读取返回错误主题 | readTicket / equals / $.payload.subject |
| G702 | visitor 越权读取泄漏 | readTicket / http_status，应为 403 |
| G703 | 关闭操作未生效 | closeTicket / equals / $.payload.state |

工具错误、规划被拒绝及未执行不能算检出；缺少正常对照通过不能计入配对检出。
每题保留生成、正常对照、故障三个位置，共九个报告位置；失败或未执行不移出分母。
正常对照的断言失败计误报，故障目标完整 PASS 计漏报，基础设施或意图失败另列不确定。
全部为 DEVELOPMENT_ONLY／UNREVIEWED，human_reviewed=0、formal_eval_v2_score=null。

先固定回复验收，再冻结源码、准确出站请求、任务和预算。用户已授权同项目同模型
常规验证自主控制预算；本轮最多 **3 次 ecnu-plus、预留 72,288 Token**，每题首次
调用一次、不重试。未知 usage 或基础设施错误停止后续真实调用并保留未执行位置。
业务目标均为新建进程内工单实例，无 Java、真实数据库、生产服务或新依赖。

```powershell
.\.venv\Scripts\python.exe scripts/check_ticket_faults.py --output runs/ticket-faults-offline
.\.venv\Scripts\python.exe scripts/check_ticket_faults.py --verify runs/ticket-faults-offline
```

公开命令只有固定回复离线验收与归档冷评分，没有真实模型运行开关；固定回复的
Token 为模拟值，配对重放不计新增模型调用。

## 实际结果

公开离线命令完成三次固定回复生成和六次同计划配对执行：三个正常对照通过，
三种指定故障被对应断言检出，450 Token 全部为 SIMULATED。
冻结后 ecnu-plus 每题仅调用一次，结果如下：

| 任务 | 初次正常执行 | 同计划正常对照 | 同计划故障目标 | 真实 Token |
| --- | --- | --- | --- | ---: |
| G701 主题一致性 | PASS | PASS | ASSERTION_FAILED，主题相等检查失败 | 2,138 |
| G702 读取权限 | PASS | PASS | ASSERTION_FAILED，预期 403 的状态检查失败 | 2,248 |
| G703 关闭状态 | PASS | PASS | ASSERTION_FAILED，关闭响应的 state 检查失败 | 2,324 |

共 **3 次真实规划、6 次固定配对重放、6 PASS／3 ASSERTION_FAILED**，
**6,710 Token、23 次进程内业务请求**，全部实际调用 HTTP 200、usage 已知。
三题计划／意图完成 3/3，配对故障检出 3/3，正常对照 3/3，误报、漏报和不确定项
在本轮均为 0；没有未执行位置、重试、备用回复或断言修改。
G703 在关闭响应断言失败后停止，未执行末尾读取；不能声称所有计划步骤都执行完毕。

模型负责事先生成测试计划，故障由已有确定性断言检出；未验证模型在失败后自主
诊断根因、修复程序或发现未知业务规则。三次生成不算九次真实模型调用，六次
固定重放也不算六次独立生成。新文本仍沿用已覆盖任务族，无独立审核、大样本
或陌生第三方写入证据，不能承诺任意项目的检出率。
