# F4 复验方案（2026-11-08）

第四轮验收已达成，但 F4 这一篇同时暴露了三类问题：冻结 rubric 多了一条原文没有的读取、
第二轮的聚焦拒绝来自两版不同的原因、以及"未批准断言 + 动态来源 + 独立执行"的组合边界没有被
干净地测到。本轮只做**独立复验**，不重跑第四轮任何位置，也不修改第四轮冻结结果。

## 1. 范围

1. 先用确定性 lint 证明第四轮 F4 的 rubric 与原文不一致（可检出），并证明三条新 rubric 一致。
2. 三条全新混合需求（新措辞、新夹具、新受众、新路径），覆盖数据绑定、未批准断言、独立执行与
   待审问题，各跑 2 版本 × 2 轮 = 12 个真实 ecnu-max 首位。
3. 失败按三类归因：产品失败 / 模型规划失败 / 夹具与 rubric 缺陷。
4. 不进入第五轮 A/B，不重新评分第四轮旧题。

## 2. 三条冻结原文

| 编号 | 原文 |

| G1 | warden 读取 registerId=31 的登记簿；用它响应中的 $.entries[0].entryId 交给 registrar 读取条目；核对条目的 $.label 等于 "draft"；随后匿名查询码头状态。 |

"连读两次"），因此失败不会被误判为措辞覆盖不足；这一点单独披露。
