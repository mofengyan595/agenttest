## 可复用交付与边界

[只读配置样例](../examples/portability/petclinic/provenance.json)提供人工限定 OpenAPI、只读目标、批准策略、两份 TaskContract 和固定 Scenario。`.plan.json` 为操作员固定计划，不是模型原始回复。TaskContract 绑定的是该契约／目标／策略，不能拿到其他实例直接当作已审核预期；前提是全新 H2 种子数据、鉴权关闭。

基础环境的离线检查覆盖这些精确输入可解析、参数封闭、角色为空时可规划、需求摘要绑定有效、改成其他 ID 被原需求和策略校验拒绝。它不启动 Java 或调用模型。已有自建课程／工单离线验收继续保留。

结论限于：同一通用规划与可信执行链可以配置接入真实第三方 REST 服务，并完成本轮两条只读任务。第三方鉴权、写入、跨接口资源依赖、异步、缺陷注入、大样本、多轮稳定性与自动生成可信预期仍未验证。保持 DEVELOPMENT_ONLY／UNREVIEWED、human_reviewed=0、formal_eval_v2_score=null；不能与先前不同任务分母合并为泛化成功率。
