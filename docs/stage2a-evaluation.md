## 调用与消耗

- 配置模型：ecnu-plus；学校兼容协议，关闭思考模式，json_schema 约束输出。
- 连通性 GET models：1 次，HTTP 200、模型存在，0 次生成。
- 结构探测及两类端到端演示：3 次生成，3465 Token；分别生成 1/3/5 步计划，两类业务计划摘要不同且均 PASS。
- 完整任务评测：18 次生成，16761 输入 + 6571 输出 = **23332 Token**。每次至多 2048 输出，累计预算 60000，无重试、无并行。

- 本轮全部真实生成合计 **21 次、26797 Token**；另有 1 次零生成的模型列表请求。学校 usage 为其返回的估计值。
