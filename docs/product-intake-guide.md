# 通用接入与真实模型使用（2026-10-26）

正常产品入口现在使用已配置的真实模型；未配置时显示缺失并阻止执行，不回退模拟。
模拟体验需要显式 `-Demo`，与正常数据目录分开。默认测试和CI仍离线，不产生付费调用。

## 开始使用

已准备Python/Node环境后，从仓库根目录执行：

```powershell
npm.cmd --prefix web run build
.\scripts\start_web.ps1
```

打开 http://127.0.0.1:18012 。模型设置沿用本机 `.env` 的 `OPENAI_API_KEY`、`OPENAI_BASE_URL`、
`AGENTTEST_MODEL`；也可通过 `-ModelEnv` 指定本机文件。服务启动不会生成模型调用，点击开始测试才调用。
进程环境优先于文件。配置、Key和测试账号不要发到聊天或填入任务文字。

本次交付保留了18012上的旧模拟进程，新版实际已启动在 http://127.0.0.1:18014 。直接使用18014，
需要自行启动时使用`-Port 18014`并先关闭同端口已有进程；不要同时启动同一数据目录的两个服务。

## 接入自己的接口

1. 填项目名称，上传OpenAPI 3.0/3.1 JSON/YAML。
2. 在通用配置中点击“读取接口并配置”。这里仅解析，不访问目标、不调用模型。
3. 填写隔离测试服务的HTTP源地址，不含路径、参数或账号。接口路径来自文档，文档servers不授予权限。
4. 选择要测试的接口，设置可读的操作名称、预期HTTP状态和必要的响应字段检查。
5. 核对请求输入。输入来自上一步接口时，选择来源操作及取值位置，例如`$.id`。
6. 需要身份时，添加Bearer或登录配置，按操作选择身份。登录操作也应选中，并指定账号字段和Token位置。
7. 确认这是已授权隔离环境、核对接口和规则，再保存。涉及POST/PUT/PATCH/DELETE还需明确允许测试写入。
8. 检查变成可提交后，进入测试助手，用刚才的操作名称或operationId交代任务。

输入值和业务预期由操作者明确确认。系统保存独立项目与规则，不要求预先编写业务适配器、
固定Scenario或TaskContract。模型只提出计划，原授权、契约、意图、依赖和断言门禁继续生效。
本轮输入按确认的字面量固定；已有套件只在批准规则内派生候选，不会自动批准未知负例。

新文档不需要匹配内置工单或课程契约。已保存登记、配置版本和确认来源可跨刷新/重启读取。
改变配置后需要重新确认，旧任务与固定资产不能绕过版本检查。

## 身份和环境

凭据只在服务端提供。通用项目的凭据变量限于`AGENTTEST_TARGET_*`命名空间，例如：

- `AGENTTEST_TARGET_BEARER_1`
- `AGENTTEST_TARGET_USERNAME`
- `AGENTTEST_TARGET_PASSWORD`

可在本机`.env`填值，或在启动进程环境提供；网页只填变量名称，配置后重启服务。
不会将模型密钥拿作业务Bearer，已知凭据出现在上传内容或输入时拒绝保存。

默认允许本机回环隔离服务。私网IP需由操作者在启动环境的`AGENTTEST_INTAKE_AUTHORIZED_IPS`
显式登记（英文逗号分隔），仍经过原TargetConfig检查。公网、生产、云元数据、未知DNS目标
及跨目标重定向不支持。确认界面不代表服务一定可达，实际可达性由执行结果反映。

## 发起和复测

例如配置了“获取仓库编号”和“读取仓库详情”，并确认编号依赖后，可以输入：
“获取仓库编号，然后读取仓库详情”。实际步骤、模型用量、完成情况和未执行原因在结果中查看。
不识别的业务要求仍待补充，不自行发明断言或修改失败计划。

通过的受支持场景可以保存固定包。正常产品对只读HTTP场景支持独立固定复测，复用原执行器、
新run及原断言，模型禁用；不是恢复旧请求。包含写入或登录的真实场景当前仅提供导出，
网页固定复测尚未开放。独立合成演示的固定复测保持原能力。

## 当前范围

- 普通标量JSON请求、标量查询/路径参数、匿名/Bearer及显式登录身份。
- 明确的跨接口动态ID依赖；状态码和受支持JSONPath字段断言。
- 每个项目最多选择30个操作；请求、模型和Schema受原有预算约束。
- 复杂嵌套输入、任意上传、轮询、任意自然语言和未知业务语义尚不通用；不支持的接口显示原因。
- 本地控制台，仍不是公网部署或多租户服务。会话、尚未保存的导出上下文等限制沿用前一版本。

用户实际环境尚未提供，本轮只完成通用接入和自建只读目标的真实模型验收，不宣称陌生业务可靠性。

## 模拟体验及旧数据

```powershell
.\scripts\start_web.ps1 -Demo
```

正常数据在`runs/product-workspace/`，模拟数据在`runs/web-workspace-demo/`。
旧模拟数据未删除；可使用`-Demo -Data runs/web-workspace`读取。两种启动都只绑定本机。
