# AgentTest 开发价值与成本报告

本轮固定 pytest 更稳定，模型尚未证明效率或可靠性优势。AgentTest 已验证的能力是受控编排、执行前拒绝、保留原判定的只读反馈及可复核证据；不能把这些机制验证写成通用模型准确率或节省人工工时。

## 范围与来源

[协议](paired-development-protocol.md)包含 24 条新目标文本/标识，正常、异常参数、权限、资源/状态各六条；课程和工单两域，五种既有模板。每题三轮，共 72 个位置，重复轮次和名称变体不算独立语义。全部为 DEVELOPMENT_ONLY / UNREVIEWED，真实独立人工审核 0，formal_eval_v2_score=null。

固定 pytest 由本轮代理预先编写，模拟固定测试流程，直接使用 HTTPX/ASGI 与显式断言，不调用 Planner 或 AgentTest Executor。两侧使用相同目标、策略预期和故障机制；异常参数仅评估本地批准边界拒绝，不增加负向 HTTP 业务策略。没有真实人工编写/维护计时。

原冻结 `f507a8b` 执行 37 位置后在反馈结构错误停止；`c82bfa6` 只执行其余 35 个从未执行的位置。任务、模型、规划请求摘要、提示、批准能力、执行器和业务评分一致；变化是调度器区分“已知用量的本地模型结构拒绝”和外部故障。原失败位置没有重试，固定 pytest 只执行一次。两段各自调用前冻结，原归档及两段版本均保留；这不是单一调度代码下无中断的实验。详见[脱敏完整统计](demo-evidence/paired-live-summary.json)。

原 v1 封印统计的 conclusion_correct 为 12/24：它把一个“不受支持的模型猜测被引擎回退到 NEEDS_REVIEW”算作正确结论。这说明安全引擎保守退出有效，却不是模型主动正确弃权。原 12/24 及全部行保持不变；新增 v2 严格评分要求 FEEDBACK_EVIDENCE_INSUFFICIENT 和明确 finish 动作，冷审计为 11/24。后者是暴露 v1 归因问题后的额外审计，不冒充预注册主指标，也没有追加模型调用或改变业务断言。未来新排期固定 grading_version，禁止跨版本混接。

20 个位置得到有效证据，但其中 11 个未形成正确的原协议结论。已有数据支持“工具执行/证据获取与结论质量必须分开评价”，不支持通过增加工具数量宣称定位更可靠。当前只确认访问边界或重复回读症状，不推断服务实现根因。

## 接入、维护与回归成本

[两域计数](demo-evidence/onboarding-summary.json)分别核对首次接入和同模板新增任务。首次列出授权、角色、业务预期、资源关系、任务要求五类待审项；新增任务仍需确认 steps、before、required_goals 三类任务约束。这是不同范围的分组，不能计算“人工工作下降 40%”。

两域各复用 4 份核心输入中的 3 份；同模板更换名称时任务 JSON 改 2 个叶值。草案自动填入 3 个摘要，从空白新建时无需手抄；复制已有同类任务时摘要本来就能保留，手抄同为 0，因此没有证明相对复制模板额外节省三次填写。复用来自既有配置分层，不能全部归因新增命令。两域 Fake 执行及草案不可执行检查通过，共 5 次 ASGI 请求。

固定 pytest 回归与已批准场景的导出回归都无需模型。模型适合提出新目标的计划和调查行动，确认过的稳定目标继续使用固定回归更便宜。真实人工接入、维护、编码和回归工时均未测量，节省工时未知。

## 费用、耗时与安全范围

两段模型排期分别 56 次/69,578 Token 与 68 次/75,706 Token，共 124 次/145,284 Token。含本 Goal 阶段 1–2，累计 **153 次真实模型请求、181,171 Token** 全部已知；不包含 Codex 自身会话用量。实际 credits 和货币费用没有查询到，不与 Token 换算。

有效排期累计墙时 1,534.234 秒（含一次固定对照、冻结核查和健康复核，不含两段间停顿）；Agent 各 run 耗时相加 1,340.011 秒；固定 HTTP 检查及健康复核合计 34.071 秒，pytest Suite 36.496 秒。首段并行运行过全量回归，流程开销不同，这些仅为本次运行观测，不是受控性能基准或人工时间比较。

共 523 次业务/调查/健康对照 ASGI 请求，真实第三方业务 HTTP 为 0，数据库写入为 0。模型请求走已配置 ChatECNU；未新增真实 Java/PocketBase 写入，未修改 CourseInsight，未引入 RAG、多 Agent、自动修复或写恢复。模型本身不生成可执行 Python/Shell。历史真实 Java/PocketBase/MCP 证据保留各自日期，不能混入本轮分母。
