- 候选仍为 `bc1b10da40561eb186acbd0944cad212ffbe9246` 的逐文件Git对象导出，
  基线仍为ecc362c；均不是branch或worktree。新交付/调度代码不进入被比较引擎。
- 原文、TaskContract、批准策略、契约、Schema、模型载荷、参数、安全预算、评分版本、
  标签及顺序全部复用原freeze；每份载荷在付费前再次逐项比较。
- 每个新run仍最多4次模型、2次只读调查、零隐式重试；后段最多284次请求，
  原72位置预留上限不扩大。后段新出现用量未知或外部失败仍停止后续位置。

按原评分协议重新汇总72个位置；不会覆写旧“停止”成绩。
